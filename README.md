## 🚀 Featured Projects

### 🦅 [Hüma Lang](https://github.com/VastSea0/huma-lang) — *Flagship Research Project*
> A high-performance, Rust-based programming language with **Turkish syntax**.  
> Explores how native-language programming affects cognitive load and developer accessibility.  
> Features a hybrid Bytecode VM, custom compiler pipeline, and a growing NLP library (`nlp.hb`).  
> 📄 Paper accepted at **ICETOL 2026** (Bremen, Germany): *"A Turkish grammar-aware approach to introductory programming"*

### 📒 [Notia Mobile](https://github.com/VastSea0) — *Active Development*
> Cross-platform productivity app built with **Flutter & Dart**.  
> A new way to capture notes, memories, and ideas — with a focus on intuitive UX and high-performance state management.

### 🌐 Hüma Browser — *Teknofest 2024 National Finalist*
> A privacy-first browser that evolved from a Teknofest finalist project.  
> Migrated from Electron/WebKit to a custom **Firefox-based (C++/JS)** engine.  
> Benchmarked for tracking protection and resource isolation, targeting the Pardus OS ecosystem.

### 🎮 Marash's Gangs — *Madalyon Game Jam 2025 — 🏆 Art Category Winner*
> A 1920-themed resistance game built in **48 hours** with Godot Engine.  
> Won for technical art direction and historical narrative design.
